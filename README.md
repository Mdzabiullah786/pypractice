# Python Programming Practice

A collection of beginner-friendly Python exercises and notes covering core language concepts. The repository is organized as individual practice files, so you can read a topic and run its examples independently.

## What you will find

- Basic syntax, variables, input and output, and type conversion
- Numbers, strings, indexing, slicing, and string formatting
- Operators, comparisons, and conditional statements
- Lists, tuples, sets, and dictionaries
- `for` and `while` loops, nested loops, and loop control
- Functions, lambda expressions, `map`, `filter`, `reduce`, recursion, and scope
- Classes, objects, constructors, and introductory object-oriented programming
- Small exercises such as prime checking, greatest common divisor, simple calculations, and list transformations

These files are learning notes and experiments rather than a packaged application. Some examples are comments or enclosed in triple-quoted strings; uncomment or edit an example when you want to try it. Several active examples ask for input in the terminal.

## Repository contents

| File | Main topics |
| --- | --- |

| `secondprogramme.py` | Data types, object size, strings, indexing and slicing, logical operators, and type conversion |

| `fourthprogramme.py` | Tuples, sets, dictionaries, nested data, and conversions |

## Requirements

- Python 3.10 or newer is recommended. The notes include `match`/`case` syntax, which requires Python 3.10+ when that example is enabled.
- No third-party packages are required. The examples use Python's standard library.

Check your Python installation:

```bash
python --version
```

On some systems, use `python3` instead of `python`.

## Run an example

Run one file at a time from the repository directory. Quote filenames that contain spaces or punctuation:

```bash
python loop.py
python "firstprogramme.py"
python "5th programme.py"
python "built in().py"
```

When a script prompts for a value, type it into the terminal and press Enter. For example, `loop.py` asks for a number for its prime checks, then asks for two numbers for the GCD exercise. The examples are separate; there is no single application entry point.

## Suggested learning path

1. Start with `firstprogramme.py` and `secondprogramme.py` for syntax, values, and input/output.
2. Continue with `third programme.py`, `fourthprogramme.py`, and `5th programme.py` for strings, conditions, collections, and operators.
3. Practice repetition and control flow with `6th programme.py`, `7thprogramme.py`, and `loop.py`.
4. Explore reusable code in `function1.py` and `function2.py`.
5. Finish with `oops.py` for classes and objects.

## Next topics to learn

The repository currently focuses on Python fundamentals. These topics are a suggested roadmap for expanding it over the coming weeks or months:

1. **File I/O** — open, read, write, and append to text files; use `with open(...)` to close files safely.
2. **Errors and exceptions** — handle invalid input and file errors with `try`, `except`, `else`, and `finally`; raise exceptions when needed.
3. **Modules and packages** — organize code across files, import your own functions, and use standard-library modules.
4. **Working with data files** — read and write CSV and JSON data using Python's standard library.
5. **Object-oriented programming** — practice inheritance, encapsulation, and composition with small examples.
6. **Practice projects** — combine these skills in small command-line programs, such as a contact list or expense tracker that saves data to a file.

As you study each topic, add its examples as a new, clearly named `.py` file and update the repository contents table above.

## Working with the examples

1. Open a file and read the comments around an example.
2. If the code is commented out or inside a triple-quoted block, enable just the example you want to run.
3. Save the file and run it from a terminal with Python.
4. Change the values or input and observe how the output changes.

Some files contain many examples, so enabling every block at once can produce confusing output or repeated input prompts. Try one example at a time.
